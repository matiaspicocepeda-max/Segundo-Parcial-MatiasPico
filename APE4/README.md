## 🎯 Objetivos

1. Relacionar clases mediante **atributos** (composición) y **parámetros** (colaboración/referencia).
2. Identificar la **firma de un método** y utilizar correctamente los **tipos de retorno** (`void`, `boolean`, `double`, `String`).
3. Implementar un programa en Java donde varios objetos interactúen entre sí de manera estructurada.

## 📁 Contenido del Repositorio

| Ejercicio | Tema Principal | Descripción Resumida |
| :--- | :--- | :--- |
| **Ejercicio 1** | Objeto como Atributo | Clase `Libro` que contiene un atributo de tipo `Autor`. |
| **Ejercicio 2** | Firmas de Métodos | Clase `Rectangulo` con métodos para área, perímetro, verificación de cuadrado y descripción. |

| **Ejercicio 5** | Colaboración de Clases | Sistema de `Biblioteca` con interacción entre `Usuario`, `Libro` y `Prestamo`. |
